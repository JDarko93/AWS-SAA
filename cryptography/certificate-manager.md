## AWS Certificate manager

- Cloud based PKI solution managed by AWS

- You are able to manage Public and Private PKI certificates

- Private CA-issued certificates are not trusted by default

- Easy certificate provisioning. No key generation, no CSR (Certificate Signing Request) submission

- Built in certificate management

- Create, import and renew certificates


### Certificate Usage 

- Authenticating user / devices

- Encrypting email messages

- Digitally signing email messages

- Verifying the validity of digital security tokens

- Encrypting data at rest

- Securing HTTPS connectivity to a web application


### Network encryption

- Secure Socket Layer (SSL) is deprecated

- Transport Layer Security (TLS) should be used. At least version 1.2

## AWS Key Management Service (KMS)

- Centralised managed service that allows you to create and managed keys

- Cloud Hardware Security Module (HSM) are tamper-resistant cryptographic devices designed to deal with cryptographic ops like creation and storage of keys. Some regulations require you to have this


### Lifecycle management

- Determines who has access and how frequently the keys are changed

- There isnt an automated way to rotate keys for ASYMMETRIC keys or imported keys

- SYMMETRIC keys have automated ways to rotate the keys

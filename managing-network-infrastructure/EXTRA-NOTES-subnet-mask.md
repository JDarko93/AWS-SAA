## VPC

### Subnet Masking

- The subnet mask basically allows part of the underlying IP to get additional next values from the base IP
- The amount of devices you are able to create within a network

### Octets
- An IPv4 address consists of 32 bits, split into 4 octets. For example. 192.168.1.0
#### ___.___.___.___
#### 1st.2nd.3rd.4th

- /32 no octets can change
- /24 only 4th octet can change
- /16 3rd and 4th octets can change
- /8 2nd, 3rd and 4th octets can change
- /0 all octets can change

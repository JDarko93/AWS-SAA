## The Open Systems Interconnect (OSI Model)

- The OSI consists of 7 conceptual layers
- Used to map network hardware and software 
- Used to explain steps taken by sending and receiving network transmission over wired, wireless, LAN, TCP/IP, IPv4 etc


### OSI Model Layers

- All People Seem To Need Data Processing

#### 7 Application
#### 6 Presentation
#### 5 Session
#### 4 Transport
#### 3 Network 
#### 2 Data Link
#### 1 Physical


### Layer 7 Application
- High-level apps (HTTP and SMTP)
- The HTTP request, method etc

### Layer 6 Presentation
- Data presentation such as is the data compressed, encrypted and character sets

### Layer 5 Session
- Deals with establishment, maintenance and tear down session

### Layer 4 Transport
- TCP (reliable, connection-oriented. 3 way handshake) establish connection between request and receipt
- UDP (Unreliable, connectionless) quicker but doesnt establish a connection between nodes

### Layer 3 Network
- Packet Routing to remote networks and IP addresses 


### Layer 2 Data Link
- Deals with gaining access to transmission media and MAC addresses
- Switches are layer 2

### Layer 1 Physical layer
- Deals with cables, connectors, wire and wireless network connectivity

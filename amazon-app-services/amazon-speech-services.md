## Amazon Speech-related services

#### Use cases are
- Voice to text
- Web app customer service chat bots
- Text sentiment analysis, span detection


### Natural Language processing (NLP)

- This is a form of AI allowing computers to meaningfully process text and voice data in some way


### Amazon Comprehend

- Used to derive insights from various text sources
- Used to detect and redact (black out) PII
- Multiple spoken language support


### Amazon Polly

- The name Polly comes from a parrot 
- Cloud based text-to-speech service
- Provides broad spoken languages
- Includes male and female voices 
- Also customisable with different voices if you want

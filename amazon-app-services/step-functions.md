## AWS Step functions

- Step functions allow you to make lambda code less complex
- Step functions can still chain simple lambda functions togethher 
- It allows your to structure your lambda functions for example what order things should happen

- Standard = maximum duration of step function max 1 year
- Express = maximum duration of step funtion max 5 minutes

- It allows you to write you own code to structure the order of your lambda functions 
- It also allows you to use design flow which uses diagrams to create your step functions
